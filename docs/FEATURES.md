# 文本特征定义与输出合同

所有表以 `qa_id` 与 `stock_code` 标识记录；ID由输入CSV行顺序和原始关键字段生成，向量清单绑定相同顺序。原始重复QA不擅自去重；如需去重，应在新实验中明确制定规则。

| 输出 | 定义 | 可用时间 |
|---|---|---|
| question_length | 问题字符串字符数 | 问题时间 |
| question_sentiment | P(positive)−P(negative) | 问题时间 |
| question_event_* | 固定词表的0/1匹配标记 | 问题时间 |
| reply_length | 非空回复字符数 | 回复时间 |
| reply_sentiment | P(positive)−P(negative) | 回复时间 |
| reply_lag_days | 回复时间减问题时间，秒数除86400 | 回复时间 |
| relevance | (问题与回复归一化向量点积+1)/2；缺任一文本时缺失 | 回复时间 |
| template_ratio | 固定套话出现次数乘字符长度之和/回复长度，上限1；允许重叠计数 | 回复时间 |
| novelty | 1−当前回复与同公司更早日期全部回复的平均余弦；首日无历史则缺失 | 回复时间 |
| reply_event_* | 回复自身固定词表的0/1匹配标记，不继承问题内容 | 回复时间 |
| calendar_day_counts | 各公司按问题或回复自身时间的自然日计数 | 自然日描述统计 |

向量使用所选分类器的编码器参数，包括MacBERT本地微调后的参数；attention mask均值池化包含模型特殊token，L2归一化；文本截断长度由 `max_length` 决定。空文本不产生有效语义向量。词表、模板短语和超参数在prepare时随协议冻结。

九类关键词分别为财务业绩、合同订单、产能、价格、诉讼、监管、风险、持股变动、产业政策。此处为可复现字典标记，不等同于后续RDIGF工程包含实质回复判定的复杂事件规则，也不宣称构成完整Q12/A19指标集。

`question_features.csv`只包含问题字段；`reply_features.csv`只包含已回复记录及回复/交互字段。无回复不伪造零情绪或零新颖度；日度数量表只保留出现的公司日，不填补交易日或停牌日。
